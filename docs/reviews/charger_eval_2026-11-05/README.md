# Charger replacement evaluation, round 1 working material (2026-11-05)

Agent working files behind `docs/charger_replacement_evaluation_2026-11-05.md`: board interface spec,
incident re-check (with an ML0227 decode), firmware/system blast radius, one dossier per shortlisted
charger, the LTC4015 wiring mockup, and the Path B (re-spin) analysis.

**Caveat:** no candidate charger datasheet or EVM user guide was readable in this round (vendor domains
blocked by the session network policy). Candidate-side numbers are search snippets or recollection and are
UNVERIFIED until gate G0. Round 1 was also written before the operator ruled (2026-11-05) that regen
harvest AND fuel-cell charging are both hard requirements, and that Path A (charger wired to the current
board) is preferred if fully feasible; the decision document's framing of regen as "demonstration value"
is superseded by that ruling.
