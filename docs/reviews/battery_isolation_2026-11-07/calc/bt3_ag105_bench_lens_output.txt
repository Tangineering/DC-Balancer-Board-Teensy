----------------------------------------------------------------
  8-bit DSO at 1 mV/div: LSB 31.2 uV = 62 mA of pack current
  8-bit DSO at 2 mV/div: LSB 62.5 uV = 125 mA of pack current
  S0-2 steady criterion 0.05 A: 25.0 uV on the shunt
  criterion margin to the simulator sink limit (I_set+0.3 vs I_set+0.2) 0.10 A: 50.0 uV on the shunt
  full regen I_set 1.75 A: 875.0 uV on the shunt

     3x larger converter ripple; a blind module clamped by a simulator sinking at I_set+0.3 A differs

Section 4. Single-bit corruption of the commissioned registers
--------------------------------------------------------------
  reg 0x01 = 0x08:
    bit 0 flipped -> 0x09: 3S 11.7
    bit 1 flipped -> 0x0A: 3S 12.0
    bit 2 flipped -> 0x0C: 3S 12.6
    bit 3 flipped -> 0x00: resistor mode, VSEL open: 4.2 V
    bit 4 flipped -> 0x18: 4.2 V default (Table 8)
    bit 5 flipped -> 0x28: 4.2 V default (Table 8)
    bit 6 flipped -> 0x48: 4.2 V default (Table 8)
    bit 7 flipped -> 0x88: 4.2 V default (Table 8)
  reg 0x00 = 0x00:
    bit 0 flipped -> 0x01: 2500
    bit 1 flipped -> 0x02: 2000
    bit 2 flipped -> 0x04: 1500
    bit 3 flipped -> 0x08: 500
    bit 4 flipped -> 0x10: 1000 mA default (Table 8)
    bit 5 flipped -> 0x20: 1000 mA default (Table 8)
    bit 6 flipped -> 0x40: 1000 mA default (Table 8)
    bit 7 flipped -> 0x80: 1000 mA default (Table 8)
  reg 0x01: three of eight single-bit errors (0x09, 0x0A, 0x0C) select a 3S charge voltage.
