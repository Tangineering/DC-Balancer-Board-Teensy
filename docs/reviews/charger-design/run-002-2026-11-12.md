# charger-design run 002 (2026-11-12): final independent audit of the r9 design

Target: `docs/charger_bq25798_wiring_design_2026-11-05.md` at revision r9, change rows r9-1 to r9-9, on branch
`charger-evm-round4`. The r9-9 section H re-run (`docs/reviews/charger_eval_2026-11-05/round4/calc/r9_calc.py`, output
`r9_calc_out.txt` and `r9_calc_out.json`) is the calculation basis. The CR netlist is `hardware/charger_evm_r8/cr/cr.net` (78 parts).
This run is step 3 of the D-50 round order (`hardware/charger_evm_r8/LAYOUT_DECISIONS.md` D-50). It replaces run 001
(`run-001-2026-11-10.md`) as the certification candidate, and it certifies nothing until the fixes are applied.

## Scope

The scope is the one fixed by r9-8 (design L.9): B.1, B.3, B.6, B.7, F.2-F.5, G.2, G.3, J.1, the A.8 adjacent-pair short table for
the 10-conductor J-TAP cavity map, and the dispositions of design Table L.9-1.

Three operator rulings of 2026-11-12 (later) bound the run:

- **(a) Heights.** The planned TSW/SSQ stack-up (CR underside 11.05 mm above the MB) is taken to clear every MB component under the
  CR except the power terminals J-BL, J-FC and J-BT (21.70 mm). The only height requirement kept is that no part of the CR outline
  (x >= 18.584) overlaps a terminal body in plan. The section 6 height survey of the change request is closed on that basis and is
  outside this run.
- **(b) Round order.** The operator has reviewed the README and approved continuation of the D-50 round order (check-in 1 passed).
- **(c) Table L.9-1 membership.** The two L.4 dispositions hang-fc-window-r5-gates-r1 and fr12-idle-selftests-need-motpwr-btbus-low
  enter Table L.9-1. The dispositions that rest only on the retired r7 outline, the F-pad field, the polyimide sheet, the feet or
  the B1R wedge retire with the outline and are not re-audited. This ruling is a default; the operator may override it at check-in 2.

## Method

The method is hybrid, as r9-8 fixed it:

- **Adversarial review** (IDs ADV-R2-01 to ADV-R2-09) on B.1, F.3, F.5, G.3, J.1 and the dispositions of Table L.9-1.
- **Self-review** (IDs SR-SR-01 to SR-SR-20) on B.3, B.6, B.7, F.2, F.4, G.2 and the A.8 table.
- **Verification.** One finding-verifier agent per finding checked the claim against the design text, `cr.net`, the decision
  records and `r9_calc_out.txt`, recomputed each bound where one was stated, and set the severity after verification. The verifiers
  also gave a verdict on each disposition of Table L.9-1.

The finding IDs are kept verbatim as the review tools issued them. Line numbers refer to the design document at r9-9.

## Refuted findings and refuted parts

No finding was refuted outright. The verifiers refuted the following parts, each with the reason:

- **ADV-R2-01, blocker severity.** The loop needs two faults beyond the brake, and the existing FR-10 and FR-14(d) detectors bound it to
  about 0.59 J. T3 raises only the register image; the ILIM regen clamp still sets the ceiling.
- **ADV-R2-06, "converter safe" depends on VOH.** R132 and R131B sit between the driver and J101, so the EIB end of the shorted
  conductor is at GND whatever the driver does.
- **ADV-R2-07, unconditional loss of detection.** A pin-22 reading that is too high cannot pass proof (d), and FR-11 or EX2 latches. The
  outcome is a refused window or a latch, so the severity is minor.
