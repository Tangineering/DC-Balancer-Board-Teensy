# SDP alpha sweep artifacts, 2026-09-01

Twenty-one solved SDP policy artifacts spanning the bench-scaled alpha range
[0.0514, 0.514], plus the shipped lever-calibrated anchor. Generated by
`tools/sdp_alpha_sweep.py solve`. The full record, including the range
derivation and the offline evaluation, is `docs/modeling/sdp_alpha_sweep_20260901.md`.

- `alpha_NN_A.json` — one policy artifact per grid point, schema `sdp-policy-v1`.
- `manifest.json` — schema `sdp-alpha-sweep-v1`: the grid, both digests per
  point, convergence, charge-cell counts, share-ladder histograms, wall time,
  and the anchor verification.

Three rules apply to these files.

1. **They are offline-evaluation artifacts.** Every one is solved with an
   explicit alpha, so `alpha.mode` is `"explicit"` and
   `sdp_assert_calibrated_benchmark()` refuses all of them for the
   frontier-scored `sdp-v3` strategy. Bind a sweep point to the non-frontier
   `sdp-v2` role only, and never place its result on the EMS frontier.
2. **Pin `policy_sha256`, never `file_sha256`.** The policy digest is the
   decision law and is stable across regeneration; the file digest moves with
   `generated_utc`.
3. **They are not the shipped policy.** `tools/sdp_policies/sdp_policy_v3.json`
   remains the calibrated benchmark. Point 10 reproduces its policy block
   exactly, which is the sweep's own consistency check.
